# Vyra Studio

A visual studio demo built with Vite, TypeScript, Three.js, GSAP, and Lenis. The experience explores WebGL imagery, scroll-driven chapters, kinetic typography, motion systems, and experimental interaction design.

## Concept

Vyra is presented as a fictional creative studio focused on visual identity and digital experiences. The site is a demonstration build rather than a production agency site.

## Tech Stack

- Vite
- TypeScript
- Three.js / WebGL
- GSAP
- Lenis
- HTML / CSS

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```
